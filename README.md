Подключил Bluetooth-модуль. Теперь отправляю команды через телефон, используя терминал.
Модуль настроен на скорость 38400 бод. Проверял на 9600 — не подошло, на 115200 — тоже не подошло.

ПРОБЛЕМА:
С модуля приходили некорректные данные — причина оказалась в несовпадении скорости UART.

РЕШЕНИЕ:
Подключил Bluetooth-модуль к UART-преобразователю на ПК и через терминал PuTTY отправил AT-команду на скорости 38400. В ответ получил подтверждение, что модуль работает именно на этой скорости.
Скорость 38400 является стандартной для AT-команд данного Bluetooth-модуля.
